# 栞 Shiori

日語閱讀與單字卡工具（繁體中文釋義）。

- 每日一篇：100 篇短文（2026/10/19 起按日期開放，配合節氣與節日），另有 13 篇常駐書庫；分 N3 / N2 / N1 / 上級＋ / 古典
- 入門：假名表（平假名／片假名）與假名練習、N5 入門課文、基礎單字與語法小貼士
- 百科「世界真奇妙」：酒、納豆、鰹節、狸、奈良鹿、雪猿、鮭魚洄游、紅葉、櫻花、自動販賣機等 10 個主題，各有 N4 簡易版與 N2 完整版
- 介面可切換繁體中文／简体中文／日本語／English／Deutsch；釋義語言可單獨設定
- 段落翻譯（全部文章，預設關閉，可在閱讀頁開啟）：繁中、英文、简中（德文界面暫以英文顯示）
- 閱讀：點底線詞看釋義，選取文字可加入單字本
- 朗讀：整篇逐句朗讀（可調速度、目前句子會反白）、單字與例句發音、翻卡自動發音；使用裝置內建日語語音
- 振假名（全部／只標註詞／隱藏）、橫排／直排
- 單字本與記憶盒複習
- 單字只存在自己的瀏覽器裡，請用「設定 → 複製備份」定期備份

## 上線方式

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
網址：`https://<使用者名稱>.github.io/shiori/`
