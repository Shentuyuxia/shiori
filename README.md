# 栞 Shiori

日語閱讀與單字卡工具（繁體中文釋義）。

- 閱讀：13 篇文章，分 N3 / N2 / N1 / 上級＋ / 古典 五個程度；點底線詞看釋義，選取文字可加入單字本
- 朗讀：整篇逐句朗讀（可調速度、目前句子會反白）、單字與例句發音、翻卡自動發音；使用裝置內建日語語音
- 振假名（全部／只標註詞／隱藏）、橫排／直排
- 單字本與記憶盒複習，介面可切換繁體中文／日本語
- 單字只存在自己的瀏覽器裡，請用「設定 → 複製備份」定期備份
